IPA **non firmate**: firmale e installale con iLoader (o SideStore, AltStore, Sideloadly).

| File | Per chi |
|---|---|
| `AdBlock.ipa` | Account Apple Developer **a pagamento**: tutto incluso, compreso il blocco nelle app tramite VPN locale |
| `AdBlock-FreeAccount.ipa` | Apple ID **gratuito**: Safari + YouTube. Per il blocco nelle app usa il profilo DNS qui sotto |
| `AdBlock-DNS.mobileconfig` | Blocca le pubblicità in **tutte le app** senza VPN e senza account a pagamento. Aprilo in Safari sull'iPhone → Impostazioni → *Profilo scaricato* → Installa |

Con Apple ID gratuito ricorda: l'app usa 5 App ID (app + 4 estensioni Safari) e la firma va rinnovata ogni 7 giorni.
